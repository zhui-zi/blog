<p>如果你的 OpenWrt 设备内存有限，在 USB 磁盘上使用 swapfile 可以帮助防止运行 Docker 或其他高负载服务时出现 OOM 内存耗尽问题。以下是在 mountd 下简单可靠的设置方法。</p><ol><li>检查当前内存和 Swap 状态</li></ol><pre><code class="language-free">swapon -s   cat /proc/swaps</code></pre><p>如果 Swap 显示为 0，说明当前未使用 Swap。</p><ol start="2"><li>在 USB 上创建一个 512MB 的 swapfile<br>请根据实际的 USB 挂载路径调整命令中的路径。</li></ol><pre><code class="hljs">dd if=/dev/zero of=/tmp/mountd/disk1_part1/swapfile bs=1M count=512</code></pre><ol start="3"><li><p>确保权限安全<br>这一步非常重要。</p><pre><code class="hljs">chmod 600 /tmp/mountd/disk1_part1/swapfile</code></pre></li><li><p>将文件格式化为 Swap</p><pre><code class="hljs">mkswap /tmp/mountd/disk1_part1/swapfile</code></pre></li><li><p>立即启用 Swap 无需重启</p><pre><code class="hljs">swapon /tmp/mountd/disk1_part1/swapfile</code></pre></li></ol><p>验证命令：</p><pre><code class="hljs">free -hswapon -scat /proc/swaps</code></pre><ol start="6"><li>调整 Swap 行为推荐设置<br>降低 swappiness 值，优先使用物理内存，仅在需要时使用 Swap：<pre><code class="hljs">sysctl -w vm.swappiness=10echo &#39;vm.swappiness=10&#39; &gt;&gt; /etc/sysctl.conf</code></pre></li></ol><p>检查设置：</p><pre><code class="hljs">sysctl vm.swappiness</code></pre><ol start="7"><li>重启后自动启用 Swap<br>USB 磁盘通过 mountd 挂载的时间较晚，过早启用 Swap 通常会导致失败。这里的 init 脚本会等待直到 swapfile 确实存在，具有良好的挂载安全性。</li></ol><p>创建 init 脚本：</p><pre><code class="hljs">vi /etc/init.d/swap-delay</code></pre><p>粘贴以下内容：</p><pre><code class="hljs">#!/bin/sh /etc/rc.commonSTART=99start() {    (        for i in $(seq 1 120); do            if [ -f /tmp/mountd/disk1_part1/swapfile ]; then                logger -t swap-delay &quot;Enabling swap from mountd path&quot;                swapon /tmp/mountd/disk1_part1/swapfile                exit 0            fi            sleep 1        done        logger -t swap-delay &quot;Swapfile not found, giving up&quot;    ) &amp;}</code></pre><ol start="8"><li><p>启用脚本并重启</p><pre><code class="hljs">chmod +x /etc/init.d/swap-delay/etc/init.d/swap-delay enablereboot</code></pre></li><li><p>重启后验证</p><pre><code class="hljs">free -hswapon -slogread | grep swap-delay</code></pre></li></ol><p>一旦 USB 磁盘挂载完成，你应该能看到 Swap 被自动启用。</p><ol start="10"><li>注意事项与提示<br>Swapfile 相比 Swap 分区具有更好的灵活性。<br>尽可能使用 USB 3.0 存储设备，因为 USB 2.0 速度较慢且在高负载下不够稳定。<br>保持合理的 Swap 大小，通常 256MB 到 512MB 已经足够。<br>Swap 有助于提升系统稳定性，无法提升性能。</li></ol><p>P.S.最近买了一台GL-MT3600BE Wi-Fi路由器。虽然是四核2.0 GHz CPU，但内存仅有512 MB。</p><pre><code class="hljs"></code></pre>
