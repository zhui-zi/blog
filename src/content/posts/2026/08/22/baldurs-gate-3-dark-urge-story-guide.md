**以下包含从序章到尾声的全部重大剧透。** 攻略按当前正式版 **Patch 8** 设计；该版本加入了暗影魔法术士等十二个新子职，拉瑞安也将其定位为《博德之门3》最后一次大型内容更新，因此这套路线在现版本已经相当稳定。([博德之门3][1])

这不是“什么好事都做”的普通善人路线，而是一条更适合邪念的完整人物弧光：**主角承认自己渴望杀戮、主动追查过去、偶尔展露可怕的一面，却在真正不可逆的节点上选择克制；最终亲手击败奥林，拒绝巴尔，以一个由自己重新创造的人格活下去。** 盖尔则从追逐神性、试图用牺牲证明价值的天才，转向接受凡人的爱与有限的人生。两条人物线彼此呼应，最终形成“邪念拒绝成为巴尔的工具，盖尔拒绝成为王冠与密斯特拉的工具”的完整主题。

## 一、最终路线概览

整条路线可以概括为：

**营救林地 → 保住阿尔菲拉 → 击昏并招募明萨拉 → 与盖尔确立恋爱 → 拒杀伊索贝尔 → 克制杀死盖尔的冲动 → 影心放过暗夜之歌 → 救出月出之塔囚犯 → 盖尔拒绝自爆 → 第三幕查明邪念身世 → 盖尔放弃王冠成神 → 击败奥林并拒绝巴尔 → 解放俄耳甫斯 → 让俄耳甫斯承担夺心魔转化 → 摧毁耐色脑 → 盖尔归还王冠、获得治愈并与你结婚。**

最终预期结果是：邪念彻底摆脱巴尔；盖尔成为凡人法师和你的丈夫；卡菈克与威尔前往阿弗纳斯寻找修复引擎的方法；莱埃泽尔领导反抗维拉基斯的战争；影心与父母团聚；阿斯代伦保持衍体身份并获得自由；哈尔辛解除暗影诅咒；明萨拉、贾希拉、明斯克、罗兰、泽夫洛尔、阿尔菲拉、巴克斯、贡德信徒、公爵、奥米伦等主要角色尽量存活。

## 二、开局人物与职业构筑

### 1. 身份、种族和职业

选择起源角色 **“邪念”**。邪念可以自定义种族、外貌和职业，但背景固定为“闹鬼者”；默认白龙裔术士最有官方宣传形象感，不过为了增加种族对话和剧情反差，本路线固定选择：

**种族：席尔德琳卓尔**
**职业：暗影魔法术士12级**
**背景：闹鬼者，邪念固定背景**
**难度：战术家**

席尔德琳卓尔在第一幕地精营地、幽暗地域和大量社会对话中拥有特殊选项，同时不像罗丝卓尔那样天然倾向邪恶。暗影魔法术士则与邪念的黑暗血统、失忆和巴尔遗产非常契合，还能以魅力承担队伍主谈判者；它是Patch 8新增的正式子职。([Baldur's Gate 3 Wiki][2])

不建议第一次执行这套路线时玩荣誉模式。第二幕杀死恋人的豁免和第三幕奥林单挑都存在足以永久毁掉赎罪结局的失败结果，而战术家仍保留完整高难战斗体验和读档余地。

### 2. 初始属性与技能

初始属性固定为：

**力量8、敏捷16、体质14、智力8、感知10、魅力17。**

技能优先选择说服与欺瞒。闹鬼者本身提供威吓和医药，因此主角同时具备说服、欺瞒、威吓三种主要对话手段。剧情中的善意选择不等于必须永远温和：面对鬼婆、地精、绝对教徒和巴尔信徒时，可以大量使用欺瞒与威吓，更符合邪念“危险但受控”的气质。

专长安排如下：

* **4级：魅力+2。** 先吃鬼婆头皮将魅力从17提升到18，再加到20；前后顺序不影响最终结果。
* **8级：警觉。** 提高先攻，第三幕奥林单挑尤其重要。
* **12级：双持客。** 允许最终同时装备马科赫什基和法术之力法杖。

埃塞尔婶婶生命值降到足够低时会提出交易，可以通过对话同时取得梅丽娜和永久属性头皮；选择魅力头皮。([Baldur's Gate 3 Wiki][3])

### 3. 法术与超魔

超魔优先顺序是：

**孪生法术、快速法术、高等法术；最后一个可选延长法术。**

最终建议保留的核心法术是：法师护甲、护盾术、魔法飞弹、迷踪步、灼热射线、反制法术、加速术、火球术、困惑术、怪物定身术、连锁闪电、无敌法球。暗影魔法本身还会提供黑暗术和恶兆猎犬。

普通战斗中由邪念负责魅力对话、控制和爆发，盖尔负责范围法术、仪式法术与工具法术。第三幕取得恶兆猎犬后，可以让猎犬咬住高优先级目标，使其对你的法术豁免更加困难，再接怪物定身术和灼热射线。

### 4. 关键装备

第一幕优先拿到瓦乌金休眠地的**火花之手法杖**、幽暗地域的法术装备和精金盾；第二幕保住阿尔菲拉后取得**强效长袍**。第三幕最终装备方向为：

**编织兜帽、编织长袍、编织斗篷、法术威能手套、马科赫什基、法术之力法杖、强健护符。**

马科赫什基来自拉玛吉斯高塔下层，法术之力法杖与强健护符来自希望之邸。穿戴双法杖后，主角会拥有极高法术豁免难度和额外六环法术资源。

### 5. 常驻队伍

默认探索阵容固定为：

**邪念：暗影魔法术士**
**盖尔：塑能学派法师12级**
**影心：生命领域牧师12级**
**莱埃泽尔：战斗大师战士12级**

这一队具备对话、爆发、控制、治疗和前排。卡菈克可以在不需要莱埃泽尔专属内容时替换她。威尔、阿斯代伦、贾希拉和明斯克则在各自个人任务中临时上阵。

必须带对应同伴的区域是：养育间带莱埃泽尔；莎尔试炼场和悲伤之邸带影心；阿拉吉、尤格、卡扎多尔带阿斯代伦；钢铁王座、安苏和戈塔什带威尔或卡菈克；丹瑟隆、明斯克与谋杀裁判所带贾希拉；巫术杂货店、密斯特拉神殿和终局始终带盖尔。

## 三、全局规则：长休、存档与恋爱锁定

### 1. 长休不能省

《博德之门3》大量同伴剧情通过营地长休排队触发。招募影心、阿斯代伦、盖尔和莱埃泽尔后，**进入翠绿林地之前先做两至三次不消耗补给的部分休息**，清理盖尔、邪念、阿斯代伦等人的早期营地剧情。盖尔部分早期谈话存在阶段性窗口，过快推进林地和荒野会跳过。([Baldur's Gate 3 Wiki][4])

每完成一个大区域或重要同伴事件，就进行一次正常长休；发现营地连续有剧情时，用部分休息继续清队列。邪念第二幕杀死恋人的事件、盖尔第二幕星空恋爱、第三幕邪念身世梦境和盖尔湖上谈话都依赖长休。

### 2. 几处真正有时间压力的事件

以下地点一旦靠近或触发，必须立即解决，不要随意传送或长休：

* 听见海滩鹰身女妖歌声后，立即救米尔孔。
* 看见瓦乌金休眠地着火后，立即营救弗洛瑞克和本林。
* 靠近豺狼人围攻洞穴后，立即处理鲁根商队。
* 与尼讷塌方现场互动后，最多只允许一次长休或区域传送。
* 第三幕触发报社诋毁任务后，必须在下一次长休前替换报纸。
* 得知弗洛瑞克即将处刑后尽快越狱救她。

这些任务存在区域推进或休息触发的失败状态。([Baldur's Gate 3 Wiki][4])

### 3. 三个大型不可逆节点

**进入山隘或阴影诅咒之地前，必须解决林地与地精冲突。**

**进入影界、接触暗夜之歌前，必须救出月出之塔囚犯并完成第二幕绝大部分支线。**

**乘船进入形态池前，必须完成第三幕全部个人任务和支线。**

影界是第一、二幕大批任务的实质截断点；形态池则是游戏最终不可返回点。([Baldur's Gate 3 Wiki][5])

### 4. 固定保留的手动存档

建议长期保留八个独立存档：第一次处理阿尔菲拉前、林地庆功宴前、进入影界前、邪念杀恋人长休前、盖尔阅读《卡尔萨斯年鉴》前、盖尔觐见密斯特拉前、奥林单挑前、进入形态池前。

### 5. 盖尔是唯一恋爱对象

可以与其他同伴保持高好感，但所有浪漫邀请都应礼貌拒绝。尤其不要接受莱埃泽尔的肉体关系、阿斯代伦的庆功宴邀请、威尔舞蹈后的亲吻、哈尔辛第三幕的开放关系、明萨拉的恋爱宣言、米佐拉的夜晚、双卓尔或哈勒普的性爱。

对哈尔辛可以选择“我珍视你，但只把你当朋友”；对威尔可以参加舞蹈，但在亲吻前退开。盖尔路线中最危险的是第三幕米佐拉事件，它可能直接造成感情破裂，因此完全拒绝。

## 四、第一幕：从螺壳舰到养育间

### 1. 螺壳舰

营救“我们”，解救影心，并让影心准备命令术。最终驾驶室中对扎尔克指挥官使用“命令：丢弃”，由主角捡走永燃之刃，不必执着击杀扎尔克。

邪念第一次见到盖尔被困传送点时，**绝对不要选择幻想砍下他的手**。这个邪念选项不是单纯想象，而会真的切断盖尔的手，使他永久无法入队，也立刻毁掉本攻略的恋爱路线。([Baldur's Gate 3 Wiki][2])

### 2. 海滩与墓穴

按顺序招募影心、阿斯代伦、盖尔、莱埃泽尔，然后探索蔓生废墟，唤醒守墓人。招募四人后先长休两至三次，再进入林地。

对盖尔保持好奇和尊重：询问他的魔法，对他的隐私表示理解，不嘲笑他的病症。盖尔后续会要求吸收三件带有“盖尔可以吸收”标记的魔法物品，准备三件无用绿装即可；总共喂三件，之后不会无限索要。([Baldur's Gate 3 Wiki][6])

### 3. 翠绿林地

进入林地后和平调停阿拉丁与泽夫洛尔，随后优先完成会因推进而消失的内容：救下被熊地精偷袭的娜迪拉；说服罗兰、卡尔和莉娅留下帮助难民；从卡哈手中救阿拉贝拉；立即前往海滩救米尔孔；帮助阿尔菲拉完成歌曲。

与松鼠“木木”互动前必须先施放动物交谈。邪念在没有动物交谈时可能直接将松鼠踢死，这不是可撤回的幻想。([Baldur's Gate 3 Wiki][2])

调查卡哈时，先在仆人区找到她与暗影德鲁伊联系的证据，再去沼泽树旁取得密信，最后回林地揭露暗影德鲁伊。说服卡哈悔悟并帮助你对抗他们，不要偷神像，也不要挑起德鲁伊和提夫林的内战。

营救萨扎并秘密带她离开林地。后续在地精营地再次救她，可以完成一条跨章节的小人物支线。

### 4. 必须保住阿尔菲拉

邪念第一幕存在一次无法完全避免的营地杀人事件。正常情况下受害者是阿尔菲拉；只有在事件触发当晚她处于死亡或昏迷状态时，游戏才会改由龙裔吟游诗人奎尔出现。([Baldur's Gate 3 Wiki][4])

具体操作如下：

在第一次越过通往染疫村落的石桥前建立独立存档。先用部分休息清空当前营地事件，然后回到林地，让队伍开启非致命攻击；由莱埃泽尔或阿斯代伦潜行，用**近战** 将阿尔菲拉击昏。非致命被动只对近战最后一击有效，法术和远程攻击仍会杀死她。

击昏后立刻越过石桥或进入染疫村落附近，马上长休。营地来的是奎尔就说明成功；若仍是阿尔菲拉，读档后再清一次营地事件队列。第二天阿尔菲拉会从昏迷中恢复，之后仍能出现在庆功宴、终焉光芒旅店和第三幕。

奎尔死亡后，不要表现兴奋。选择惊恐、悔恨，尽量坦白发生了什么，并让同伴知道你正在失控。管家仍会奖励极强的**猎杀者斗篷**，但主角的叙事方向从“享受杀戮”转为“害怕自己再次伤害身边的人”。

### 5. 染疫村落

立即救下风车上的巴克斯，操作的是制动杆而不是释放制动杆。探索药剂师地窖，把夸塞魔卷轴交给盖尔抄写，之后盖尔可永久召唤铲子。

找到《塞尔死灵法术典籍》和地下蜘蛛巢穴的紫水晶，让邪念亲自阅读。第三幕取得《萨奇亚特法典》后继续解锁，最终获得亡灵召唤能力。

### 6. 晋升之路、卡菈克和瓦乌金休眠地

找到卡菈克并相信她，不要听从所谓圣武士的指控。带威尔见卡菈克，让他意识到米佐拉欺骗了自己；随后消灭安德斯一伙。

救下抓痕并邀请它来营地。枭熊洞穴中不要杀死幼崽；之后在地精营地帮助幼崽逃走，它会在数次长休后加入营地。

看见豺狼人围攻洞穴后立即处理。可以控制豺狼人首领攻击同类，最后再杀死首领。将散塔林会货箱保持封闭并交还给鲁根或散塔林会，以和平进入散塔林藏身处，再救出艺术家奥斯卡。

到达着火的瓦乌金休眠地后不要长休。救出弗洛瑞克和本林，奖励选择火花法杖，为邪念提供第一幕优质施法武器。

### 7. 埃塞尔婶婶

进入沼泽后识破幻象，救梅丽娜并追入鬼婆巢穴。战斗中将埃塞尔生命值压到约20%以下，避免沉默、持续伤害或直接击杀，并让她正常行动一次，她会主动提出交易。

对话时选择同时要回梅丽娜并索取力量，成功通过说服、欺瞒或威吓，获得**魅力+1头皮**。随后将康纳魔杖交给梅丽娜，让她带着僵尸丈夫前往博德之门，这样第三幕还能继续鬼婆幸存者和救范拉任务。([Baldur's Gate 3 Wiki][3])

### 8. 地精营地与明萨拉

先以和平方式探索整个营地。接受阿布狄拉克的洛维塔仪式，成功承受疼痛可获得生命值较低时的永久增益；营救瓦罗、利亚姆和枭熊幼崽。

带萨扎见明萨拉，替萨扎求情，使她再次存活。随后开始清除三名首领：先把女祭司迦特引到私人房间杀死；告诉哈尔辛暂时等待；最后处理明萨拉和德罗尔。

对明萨拉开启非致命攻击，确保最后一击是近战，将她击昏而不是杀死。不要用法术、弓箭或持续伤害完成最后一击。明萨拉倒地后不要长休，立刻击杀德罗尔并完成“击败地精”任务；Patch 8进一步修复了明萨拉被击昏后无法在月出之塔正常出现的问题。([Baldur's Gate 3 Wiki][7])

德罗尔死亡会让整个营地敌对，所以应最后处理。杀完三首领后回林地找泽夫洛尔和哈尔辛，确认任务完成。

### 9. 提夫林庆功宴与盖尔第一幕恋爱

盖尔的织法教学场景中，选择让魔法持续，不要故意中断；最后想象**亲吻盖尔** 或与他牵手散步。中文选项措辞可能略有差异，以“把亲密和浪漫意象传递给盖尔”为准。([Baldur's Gate 3 Wiki][8])

庆功宴先与盖尔交谈，选择带有暧昧、期待再次共享魔法或希望与他更亲近的回答。入睡时选择想着盖尔，不接受阿斯代伦、莱埃泽尔或其他人的邀请。

这一阶段盖尔可能仍保持克制，不一定发生完整性爱场景。只要织法场景完成、庆功宴表明心意，恋爱线路就已正确启动。

### 10. 幽暗地域

林地庆功宴后再进入幽暗地域。探索塞伦涅哨所、眼魔区域、鱼人海湾、蕈人栖息地和奥术高塔。

蕈人任务中帮助孢子王斯伯消灭灰矮人，但拒绝格拉特发动政变，最终杀死格拉特。鱼人海湾揭露“布尔”其实是红帽子，不要献祭同伴。

治好图拉，与奥米伦合作进行蝌蚪实验，不要攻击奥米伦和布尔格。奥术高塔阅读诗歌后与伯纳德和平对话，再探索地下室。

营救贝伦时先处理火把，避免毒蘑菇爆炸，取得贵族茎。**本路线将贵族茎交给邪念本人食用，而且要在第一次见过管家之后再吃。** 这样可恢复与邪念过去有关的残酷记忆；代价是德里丝第三幕商店不会获得贵族茎货源。这是为了邪念专属剧情而做出的明确取舍。([Baldur's Gate 3 Wiki][2])

### 11. 复仇熔炉

先找到菲尔罗敏，通过对话取得一小瓶符文火药，不要直接激怒她引爆。与尼讷塌方互动后立即完成本区域，不要反复长休。

与长老布里斯瓦合作反抗尼讷，炸开塌方，阻止尼讷杀死深地侏儒，再杀死尼讷。保住巴克斯和侏儒，为第三幕铁手侏儒与贡德信徒和解铺路。

精金熔炉制作**精金鳞甲和精金盾**，击败守护者格里姆。鳞甲交给莱埃泽尔或影心，盾牌交给影心。

### 12. 山隘与瑰晨修道院

确认林地庆功宴、幽暗地域和复仇熔炉全部完成后再进入山隘。遇到埃斯特女士时绝对不要交出真正的吉斯洋基蛋；可以直接拒绝，也可以用欺瞒让她接受枭熊蛋。

进入养育间时带莱埃泽尔。让她先进入净化装置，以获得她信仰开始动摇的完整剧情；装置开始严重伤害她时，尽早说服她离开，避免永久属性损失。让主角自己承受全部阶段虽能获得“觉醒”强化，但会削弱莱埃泽尔这段人物弧光，所以本路线不选。([Baldur's Gate 3 Wiki][9])

面对审判官后服从维拉基斯要求进入星界棱镜，但拒绝杀死梦中访客。返回后向莱埃泽尔指出维拉基斯撒谎，支持她重新思考忠诚。

取得黎明大师徽章，用正常方式获得洛山达之血，不要故意启动毁灭修道院的机关。离开养育间后长休，支持沃斯与俄耳甫斯的反抗计划。

与埃尔明斯特见面时让盖尔与他完整交谈，使魔法球暂时稳定。不要攻击埃尔明斯特，也不要把盖尔赶走。

### 13. 进入第二幕

虽然已经探索幽暗地域，但最终从山隘入口进入阴影诅咒之地。使用明萨拉的蜘蛛里拉召来卡尼斯，暂时跟随绝对教团车队。

遭遇竖琴手伏击时转而帮助竖琴手，杀死卡尼斯并取得月亮提灯。放出仙子多莉·多莉·多莉，获得覆盖全队的仙子祝福，不要碾死她。

## 五、第二幕：终焉光芒旅店、月出之塔与暗夜之歌

### 1. 终焉光芒旅店

面对贾希拉时保持坦率，可以喝下她准备的真言药酒并承认自己带着蝌蚪。与旅店所有幸存者交谈，特别是阿尔菲拉、罗兰、戴摩、巴克斯、阿特·卡拉和弗洛瑞克。

让戴摩完成卡菈克的第二次引擎升级。与奇怪的牛交谈，但克制邪念想杀死它的冲动，第三幕继续帮助它进入城市。

在与伊索贝尔谈话前长休一次。如果管家尚未出现并要求你杀死伊索贝尔，就继续用部分休息清营地事件，直到接到任务。之后主动告诉伊索贝尔自己正在对抗杀死她的冲动，再与她合作。

马库斯袭击时优先保护伊索贝尔：使用庇护术、治疗、控制和堵门，不能让她被击倒带走。伊索贝尔一旦失守，旅店结界会崩溃，阿尔菲拉、戴摩、罗兰等大量角色将死亡，这与本路线完全不兼容。

拒绝杀伊索贝尔后，管家会把目标改成主角的恋人或好感最高同伴；已经稳定魔法球并建立恋爱的盖尔可以成为目标。([Baldur's Gate 3 Wiki][2])

### 2. 罗兰、阿拉贝拉和外围任务

罗兰离开旅店后，应在靠近他的阴影区域时立即救援，不能看见战斗后离开或长休。救回罗兰，为他第三幕继承拉玛吉斯高塔铺路。

找到阿拉贝拉后送她去营地，再在治疗中心附近找到父母遗体。对她说明真相，让守墓人引导她掌握力量。

完成“惩罚恶人”、泥瓦匠行会和阴影战场支线。与奥利弗玩捉迷藏时尽量温和，不把他视为单纯怪物。

### 3. 提前潜入月出之塔

**不要先去莎尔试炼场。** 月出之塔在暗夜之歌事件前仍然是可和平渗透的城镇，必须先完成商人、同伴和囚犯内容。

在凯瑟里克审判地精时请求宽恕或释放他们，不要为了取悦绝对教团而亲手屠杀。明萨拉随后会被带走审讯，前往下层救她：进入审讯者心灵、帮助她夺回意识，再护送她离开月出之塔并正式招募。

在监狱中先杀死典狱长、巡逻守卫和侦察之眼，然后从牢房背墙同时救出提夫林与乌尔布伦一行，带他们乘船回终焉光芒旅店。返回旅店找阿尔菲拉领取**强效长袍**。

### 4. 月出之塔中的邪念和同伴内容

带阿斯代伦见血液商人阿拉吉，明确支持他拒绝咬人。不要为了力量药剂强迫阿斯代伦重演被主人支配的经历。

与泽瑞尔进行心灵交流时，可以让她看到主角对盖尔的渴望，而不是杀戮欲。厨房里的豺狼人会认出邪念过去的气味，利用心灵能力让它们摆脱厨师控制。

与猫“钢爪”交谈时，**不要选择努力回想过去发生了什么**。这个看似调查记忆的选项会让邪念在回忆中直接杀死它。([Baldur's Gate 3 Wiki][2])

进入巴萨扎房间并让盖尔检查暗影提灯仪式，选择摧毁仪式，不要鼓励盖尔驾驭阴影魔法。这会强化盖尔重新建立原则的方向。

### 5. 解除暗影诅咒

前往治疗中心，通过说服让马鲁斯·索姆和护士互相“示范”手术，取得鲁特琴。用琴唤醒阿特·卡拉，再让哈尔辛进入传送门。

传送门防守持续四轮，提前准备黑暗术、火墙术、灵体卫士和范围控制。哈尔辛归来后寻找奥利弗，告诉他萨尼尔需要他；即使开战，结束后仍选择理解和团聚。

解除诅咒的最终条件还包括击败凯瑟里克，所以此时日志可能尚未完成。只要萨尼尔与奥利弗已经重合，第二幕结尾就会正式恢复土地。([Baldur's Gate 3 Wiki][10])

### 6. 盖尔第二幕恋爱锁定

抵达月出之塔传送点、高好感且没有与其他人确立关系后，盖尔的投影会邀请主角离开营地。必须在进入夺心魔殖民地和击败凯瑟里克前通过长休触发。

跟随投影找到盖尔，选择留下陪伴，并明确表达爱意。面对他准备的星空幻境，可以选择接受魔法性爱，也可以告诉他自己想要真实的盖尔；为了与“放弃神性、接受凡人”主题呼应，本路线选择后者，但两种方式都能确立正式恋爱。第二天不要把这一夜称作偶然或一次性关系。([Baldur's Gate 3 Wiki][8])

### 7. 邪念试图杀死盖尔

拒绝伊索贝尔后，管家最终会命令邪念杀死恋人。该事件若在进入影界前已经出现，就立即处理；如果尚未出现，离开影界后、进攻月出之塔前连续长休，直到触发。

睡前让邪念装备：

**自主头盔、竖琴手护符、保护斗篷或保护戒指，并保留四点激励。**

事件中必须选择**叫醒盖尔**，然后通过关键的感知豁免，允许他把主角绑住。最关键的首次检定难度为14；后续较高难度检定主要影响对话和挣扎表现，但仍应尽量成功。([Baldur's Gate 3 Wiki][2])

这一夜是整条邪念×盖尔路线的核心：盖尔亲眼看见主角最危险的一面，却没有离开，而是守着主角直到天亮。不要隐藏、不要欺骗，也绝对不能放任邪念杀死他。

### 8. 莎尔试炼场

带影心、盖尔和阿斯代伦进入。接受拉斐尔关于尤格的交易，为阿斯代伦换取背部刻痕的解释；不要提前解决老鼠谜团，否则可能让尤格的契约走向不同结果。

可以正面击杀尤格，也可以通过对话让他杀掉部下、宠物和自己。巴萨扎建议直接在办公室击杀，避免他在影界干扰暗夜之歌。

完成影心试炼和寂静图书馆，取得暗夜之矛。**进入影界前再次确认：明萨拉已获救，提夫林和侏儒囚犯已回旅店，阿尔菲拉奖励已领取，萨尼尔与奥利弗已重合，盖尔星空恋爱已完成。**

### 9. 暗夜之歌

进入影界后不要替影心做决定。高好感情况下选择相信她、保持沉默或提醒她自己作出选择，她最终会扔掉长矛并释放艾琳女士。

不要威胁影心，也不要直接命令她放下武器。让她自己拒绝莎尔，这比一次说服检定更完整地表现她的人物成长。

### 10. 月出之塔决战

进攻月出之塔时邀请贾希拉临时加入队伍，这样你可以直接控制她，避免AI冲入敌阵死亡。清理大厅和屋顶后面对凯瑟里克。

在凯瑟里克卧室读过梅洛迪娅的信件后，可以尝试唤起他的悔意。进入夺心魔殖民地时使用阵容：

**邪念、盖尔、威尔、影心。**

救出米佐拉时让威尔在场，要求额外奖励以取得地狱刺剑。救出泽夫洛尔和“我们”，与克蕾莎完整交谈以了解她如何对邪念进行实验，再完成脑连接谜题。

首次正面对抗主脑时，盖尔可能提出利用魔法球。选择语义为：

**“你可以选择我——选择爱你的人。我们会一起找到别的办法。”**

不要让盖尔在第二幕自爆。这个选择既保住全队，也进一步引导盖尔相信自己不必通过死亡证明价值。([Baldur's Gate 3 Wiki][8])

击败米尔寇化身后招募贾希拉，确认艾琳、伊索贝尔、哈尔辛和明萨拉都在。前往博德之门的过渡战斗中帮助君主抵御吉斯洋基，但拒绝吞食星界蝌蚪，不让主角发生半夺心魔变化。

## 六、第三幕前半：利文顿与飞龙关

### 1. 先触发邪念身世和贾希拉守夜

进入利文顿后不要立刻冲向飞龙关。连续长休，直到邪念梦见巴尔并得知自己曾是巴尔教团领袖、被奥林背叛。

如果贾希拉已经入队，她会在邪念噩梦后前来守夜。因为你在第二幕没有杀死恋人，她会以一个曾经面对过巴尔之子的前辈身份鼓励主角继续反抗。邪念在戈塔什加冕礼上还会得知：自己才是与戈塔什共同策划绝对教团阴谋的人，奥林只是后来夺走了位置。([Baldur's Gate 3 Wiki][2])

### 2. 马戏团

带盖尔进行泽希诺的爱情测试，正确答案是：

第一问选择**红苹果** 或**烤洋葱**，二者都算正确；
第二问选择**盖尔在深水城阳台上最快乐**；
第三问选择**他最大的缺点是觉得自己死掉，自己和世界都会更好**。

这三问准确概括了盖尔：外表完整、内心层层隐藏；真正的幸福来自家与日常；最深的问题不是虚荣本身，而是把自我牺牲误当作爱。([Baldur's Gate 3 Wiki][11])

揭穿阿卡比作弊，被传送到丛林后取得尼鲁纳。邀请耶娜进入营地，并答应帮助奇怪的牛以苹果形态进入城内。

### 3. 利文顿支线

调查慈爱神殿谋杀案，搜查弗雷戈招待所。检查阿福地下室的危险玩具，再在夏芮丝爱抚找到他并迫使其交代烟花商店。

带阿斯代伦前往古尔营地，承诺调查失踪的孩子。带贾希拉前往丹瑟隆飞斧，识破变形怪伏击并保住杰拉杜斯；进入下城区前完成此事，否则该段可能自动结束。([Baldur's Gate 3 Wiki][4])

### 4. 夏芮丝爱抚和拉斐尔

会见拉斐尔和沃斯。拒绝签订拉斐尔契约，但告诉沃斯你会想办法取得俄耳甫斯之锤。

不要与双卓尔发生关系。无论盖尔是否表示勉强接受，这都不符合本路线的专一恋爱主题。

### 5. 戈塔什加冕礼

**必须先参加加冕礼，再去钢铁王座或钢铁卫士铸造厂。** 带盖尔、卡菈克和威尔参加。

不要在典礼现场开战。听完戈塔什对邪念过去的完整说明，承认你们过去确实合作过，但表示失忆后的自己已经不同。可以暂时接受“不互相攻击”的联盟，保留两枚耐色石，但不要对他宣誓真正效忠。

卡菈克想立即动手时说服她暂时忍耐。之后让米佐拉来到营地，面对“解除威尔契约”与“得知公爵位置”的二选一时，选择**解除威尔契约**；即使如此，仍可在钢铁王座凭自己救出公爵。([Baldur's Gate 3 Wiki][12])

立刻从飞龙关监狱救出弗洛瑞克，不要拖延她的处刑计时。

## 七、第三幕下城区：固定任务顺序

### 1. 控制奥林绑架哈尔辛

进入下城区前后，奥林会从营地候选人中绑架一人。候选优先顺序通常包括莱埃泽尔、哈尔辛、盖尔、明萨拉和耶娜；正在队伍中、已被恋爱或不符合状态的角色会被排除。([Baldur's Gate 3 Wiki][13])

为了固定让哈尔辛被绑架：

**长休前把莱埃泽尔放进当前队伍；盖尔因为是恋人不会被选；让哈尔辛、明萨拉和耶娜留在营地。**

这样奥林会优先选择哈尔辛。绑架本身没有立即开始的长休倒计时，因此无需因此提前冲向巴尔神殿；先完成下城区内容和个人任务即可。与伪装成哈尔辛的奥林对话时保护抓痕，不要攻击真正的营地动物。

### 2. 先处理《阻止新闻出版》

一旦与报社相关人物谈话并触发诋毁新闻任务，就必须在下一次长休前完成。潜入《博德之口》地下室，把印刷机中的恶意文章替换为赞扬冒险者或中立文章，再离开报社。

完成报社后，才开始需要长休触发的盖尔第三幕任务。

### 3. 盖尔第三幕任务：彻底放弃神化

带盖尔进入巫术杂货店。先处理罗兰和洛若坎：告诉艾琳洛若坎想要囚禁她，跟随她进入高塔，站在艾琳一边杀死洛若坎。罗兰存活且前两幕受到帮助时，会反抗导师并接管高塔。

随后进入拉玛吉斯高塔秘库。前往卡尔萨斯秘库的门序为：

**银手门 → 防护门 → 白银门。**

取得《卡尔萨斯年鉴》，同时进入另一路秘库取得《萨奇亚特法典》。让邪念阅读法典，再完成《塞尔死灵法术典籍》；解除法典诅咒后还会获得额外生命增益。

让盖尔阅读《卡尔萨斯年鉴》。此后他会重新产生控制王冠、甚至超越密斯特拉的念头。离开巫术杂货店后与埃尔明斯特交谈，再前往风暴海岸神殿觐见密斯特拉。

从这一刻开始，所有选项必须保持一致：

* 不夸奖盖尔有资格驾驭王冠。
* 不提议两人一起成为神。
* 不让他对密斯特拉隐瞒王冠。
* 建议他听取密斯特拉意见并寻求和解。
* 让他承诺归还王冠，换取魔法球治愈。

下一次长休触发湖上谈话。明确告诉盖尔：**你爱的是眼前这个凡人，而不是他可能成为的神；他已经足够，不需要王冠证明自己。** 盖尔的王冠倾向会累计，第三幕哪怕只在关键节点鼓励一次成神，都可能把他推向野心之神结局，因此必须从年鉴、密斯特拉到湖上谈话始终一致。([Baldur's Gate 3 Wiki][8])

### 4. 营救明斯克

先带贾希拉见九指基恩，再前往清账屋。追踪石头领主到下水道蓄水池，战斗时杀死冒牌贾希拉和其他敌人。

最后开启非致命攻击，用近战将明斯克击昏。君主开始拒绝保护他时，坚持要求君主将明斯克纳入棱镜保护；贾希拉在场能确保完整招募剧情。

招募后访问贾希拉的家，与她的孩子交谈。之后在谋杀裁判所带上贾希拉和明斯克，可获得大量与巴尔之子历史相关的对话。

### 5. 影心结局

带影心前往悲伤之邸。击败维康妮亚后让影心自己决定如何处置她；赎罪路线中的影心通常会拒绝继续成为莎尔式的施虐者。

在最深处找到影心父母时，选择**救下父母并共同承受莎尔诅咒**。让父母化为月华能带来一种完整告别，但救人会产生更长的家庭重建和尾声内容，因此本路线固定救下。([Baldur's Gate 3 Wiki][14])

### 6. 阿斯代伦结局

完成古尔营地和吸血鬼衍体袭营内容后，带阿斯代伦进入卡扎多尔宫殿。战斗开始后尽快救出被束缚的阿斯代伦，再击败卡扎多尔。

仪式结束前，阿斯代伦会请求你帮助他在卡扎多尔背上刻符文。先通过洞悉理解他正被恐惧与力量欲控制，再用说服让他停止仪式；不要只是冷硬拒绝，否则在部分对话组合下他可能离队。

杀死卡扎多尔后释放七千名衍体前往幽暗地域。这个选择危险但能完成阿斯代伦拒绝复制施害者逻辑的弧光，并在尾声产生后续。([Baldur's Gate 3 Wiki][15])

### 7. 梅丽娜与鬼婆幸存者

前往老加洛之家帮助鬼婆幸存者，制作鬼婆灾祸。到脸红美人鱼找到埃塞尔后，必须先向她投掷鬼婆灾祸，使她吐出范拉，再击杀鬼婆。

与梅丽娜重逢，确认她已经摆脱对复活丈夫的执念并成为幸存者领袖。

### 8. 神秘卡里翁与奥斯卡

先调查神秘卡里翁，找到并帮助瑟伦波。摧毁卡里翁分散在城市中的器官罐，尤其是藏在瑟伦波体内的心脏，再杀死卡里翁。

之后前往贾纳斯宅邸处理奥斯卡附身事件。先做卡里翁可以避免在宅邸任务中被迫替其办事。

### 9. 铁手侏儒与贡德信徒

这一整条任务必须按照：

**加冕礼 → 钢铁王座 → 铸造厂 → 安苏 → 戈塔什**

的顺序进行。

先潜入铸造厂了解贡德信徒家人被关押的事实，但不要立即炸毁。然后从弗莱姆货运仓库进入潜艇，前往钢铁王座。

钢铁王座队伍建议为邪念、盖尔、威尔、莱埃泽尔。提前准备加速药水、迷踪步、任意门和治疗药剂。优先救出拉文伽德公爵、奥米伦和所有贡德信徒；因为威尔已经解除契约，米佐拉会召来爆炸蜘蛛试图杀死公爵，立刻给公爵使用庇护术、治疗或任意门。

救人后返回铸造厂，保护赞纳·图宾和贡德信徒，击败钢铁卫士泰坦并摧毁控制中心。面对乌尔布伦与巴克斯的冲突时，支持巴克斯接管铁手侏儒，阻止乌尔布伦屠杀贡德信徒。([Baldur's Gate 3 Wiki][16])

### 10. 安苏与威尔

救出公爵后取得飞龙之路线索，带威尔进入飞龙岩地下，完成四项试炼并见到安苏。安苏揭露君主就是博德安，是第三幕最重要的夺心魔背景内容之一。

击败安苏后，让威尔选择成为**阿弗纳斯之刃**，而不是继承公爵之位。这样最终卡菈克引擎失控时，威尔会主动陪她前往阿弗纳斯，主角则可以留下与盖尔共同生活。

### 11. 击杀戈塔什

钢铁王座和铸造厂完成后，带卡菈克回到飞龙岩。解除钢铁卫士后戈塔什战斗明显简单。

杀死戈塔什后不要立刻离开，让卡菈克完成面对尸体的崩溃与倾诉。不要用“至少你报仇了”之类轻率回答，而是承认这场复仇无法补偿她失去的岁月，并陪着她。

### 12. 希望之邸

前往魔鬼的小费，海尔希克会认出邪念曾与戈塔什来过，并能补充二人盗取卡尔萨斯王冠的过去。邪念曾借助她闯入梅菲斯特的宝库，这也是绝对教团阴谋的源头之一。([Baldur's Gate 3 Wiki][2])

开启传送门进入希望之邸。拒绝哈勒普的性爱交易，直接战斗；救出希望，取得俄耳甫斯之锤、法术之力法杖、强健护符和其他宝物。

最终战前说服尤格背叛拉斐尔，再击杀拉斐尔。保住希望；如果科瑞拉仍活着，可以尝试使用非致命方式留下她，但这不是主结局必要条件。

取回莫尔与拉斐尔的契约，之后交还给公会中的莫尔。

## 八、谋杀裁判所、奥林与邪念赎罪高潮

### 1. 完成谋杀调查

在葡萄酒节发现多洛时立即救科拉，不要触发后离开。之后前往费加罗裁缝店救下费加罗并杀死多洛，取得装有人手的袋子。

带邪念、盖尔、贾希拉、明斯克进入谋杀裁判所。拒绝杀死小飞象瓦莱里娅，也拒绝成为邪恶刺客，直接与沙洛佛克开战。即使邪念可以由管家直接打开巴尔神殿，完成裁判所仍能获得最多的沙洛佛克、贾希拉和明斯克对话。邪念确实不必依赖巴尔护符才能进入神殿。([Baldur's Gate 3 Wiki][2])

### 2. 揭露奥林身世

在巴尔神殿侧室调查奥林母亲海伦娜的尸体，使用死者交谈，得知沙洛佛克曾命令海伦娜杀死自己的女儿。面对奥林时用这条真相打击她，可以看到奥林在“巴尔宠儿”身份崩塌时的完整反应。

邪念必须亲自主持与奥林的对话，不要让同伴走在前面触发。优先保证哈尔辛存活，再进入单挑。

### 3. 奥林单挑准备

邪念与奥林的决斗是**强制单挑**。在邪念专属决斗中，奥林不会得到旁边巴尔信徒的增援与“不可阻挡”层数；但如果邪念被奥林打倒，即使同伴之后加入并杀死奥林，巴尔仍会把这视为邪念失败，赎罪结局将被破坏。([Baldur's Gate 3 Wiki][17])

进入神殿前升到12级，让影心为邪念施放：

**英雄盛宴、六环援助术、死亡防护、行动自如。**

邪念自身使用法师护甲、镜影术和警觉灵药，装备全部提高法术豁免难度的装备，恢复满血、满法术位、满术法点。单挑前建立独立手动存档。

### 4. 暗影术士稳定打法

第一回合尽量抢先手，用附赠动作召唤**恶兆猎犬** 锁定奥林，再对她使用高等或普通的怪物定身术。猎犬会削弱目标对你的法术抗性。

定身成功后靠近奥林，用高环灼热射线轰击，命中会形成大量暴击。若定身失败，则使用快速法术连续施放灼热射线或连锁闪电，并用护盾术抵挡攻击、迷踪步重新拉开距离。

无敌法球可以用于紧急保命，但不要让奥林也进入法球范围。只要邪念被击倒或判定输掉决斗，立即读档，绝不能让队友接手完成战斗。

### 5. 拒绝巴尔

击败奥林后，巴尔会要求邪念重新成为神选。所有回答都必须明确拒绝：不为巴尔统治主脑，不接受杀戮者形态，不愿再让朋友因自己受到威胁。

巴尔会抽走邪念体内属于他的血与神力，直接杀死主角。守墓人随后出现，用自己的力量将主角复活，并指出巴尔只能杀死他创造的部分，却无法杀死主角在旅途中重新塑造的自我。复活后的邪念彻底摆脱强制杀戮冲动。([Baldur's Gate 3 Wiki][2])

### 6. 赎罪后使用“医疗术”

拒绝巴尔并复活后，在下城区、下水道或地下废墟中，让影心对邪念施放六环**医疗术**。这会触发一段特殊记忆：邪念曾被养父母收养，也曾像普通孩子一样与朋友玩耍。

不要在击败奥林之前使用医疗术。该回忆每周目只能触发一次，提前施放会锁定另一种较早的记忆版本，无法看到拒绝巴尔后的完整童年回忆。([Baldur's Gate 3 Wiki][2])

## 九、第三幕剩余支线清单

奥林和巴尔问题解决后，再进行最终收尾。此时应完成：

救出码头旁的瓦罗；完成失踪小丑德里波斯的遗骸收集；处理烟花店；完成有情众生护符和诅咒僧侣；在公会之战中支持九指基恩而不是散塔林会；处理水之女王与潜艇驾驶员的纠纷；探索君主在精灵之歌酒馆下方的旧据点；与阿拉贝拉、罗兰、梅丽娜、莫尔、泽夫洛尔等幸存者完成最后对话。

完成所有同伴任务后再乘船进入形态池。进入前确认背包中有俄耳甫斯之锤、三枚耐色石、足量加速药水、隐形药水、复活卷轴和召唤卷轴。

## 十、终局选择：解放俄耳甫斯、拒绝盖尔自爆

### 1. 形态池与耐色脑

进入形态池后与戈塔什已无联盟，因为本路线已经亲手杀死他。面对耐色脑时选择抵抗，不接受主脑对邪念过去的诱惑。

战败进入星界棱镜后，君主会要求吞噬俄耳甫斯。拒绝君主，用希望之邸取得的锤子打碎锁链，释放俄耳甫斯。君主因此离开并投靠耐色脑。

### 2. 谁成为夺心魔

不要让邪念、盖尔或卡菈克转化。让俄耳甫斯接受夺心魔变化。

这会保住邪念的人格与盖尔婚姻，也让卡菈克保持提夫林身份，为她与威尔前往阿弗纳斯寻找引擎修复方案保留希望。俄耳甫斯虽然付出巨大代价，但仍可以把反抗维拉基斯的使命托付给莱埃泽尔。

### 3. 绝不让盖尔引爆魔法球

抵达主脑脑干前，盖尔会再次提出独自上去引爆魔法球。明确拒绝，告诉他你们会一起战斗。

即使某些版本为牺牲盖尔增加了恋爱信件，这仍然意味着盖尔死亡，无法获得求婚、婚姻和凡人生活结局；因此本路线不采用。Patch 8也专门补充过恋爱状态下盖尔牺牲后的信件，但那只是悲剧补偿，不是盖尔最佳结局。([博德之门3][1])

### 4. 最终战

最终队伍使用邪念、盖尔、莱埃泽尔、影心。召唤所有盟友突破高城，盖尔和邪念保留至少一个无敌法球。

主脑顶部利用无敌法球保护开启传送门者，进入主脑意识后集中爆发。最终选择**摧毁耐色脑和所有蝌蚪**，不要以巴尔、自己或任何人的名义控制主脑。

## 十一、码头与尾声的精确选择

### 1. 俄耳甫斯与莱埃泽尔

俄耳甫斯成为夺心魔后可能请求死亡。说服他继续活下去，观察革命进展；同时支持莱埃泽尔骑龙离开，继承解放吉斯洋基的使命，而不是继续留在费伦。([Baldur's Gate 3 Wiki][18])

### 2. 卡菈克与威尔

卡菈克引擎开始崩溃时，不要让她独自死亡，也不要让主角离开盖尔陪她。因为威尔已经选择成为阿弗纳斯之刃，他会提出陪卡菈克回到阿弗纳斯。

支持卡菈克与威尔共同前往。尾声中二人会发现可能修复引擎的线索，这是卡菈克现有结局中最有希望的一种。

### 3. 盖尔与王冠

告诉盖尔按照承诺找回并归还卡尔萨斯王冠。密斯特拉会移除魔法球，盖尔不再需要靠吞噬魔法物品或死亡控制它。

盖尔随后向邪念求婚。接受求婚，选择与他回到深水城的高塔生活，并欢迎塔拉继续作为家人。盖尔会成为黑杖学院教授，而不是野心之神；这条凡人路线要求第三幕持续否定王冠和神化，并完成密斯特拉和解。([Baldur's Gate 3 Wiki][8])

## 十二、盖尔恋爱全程防断线检查表

为了便于实际游玩时快速确认，盖尔恋爱只需要牢牢记住以下节点：

**第一幕：** 招募时把他从传送点拉出来，绝不砍手；喂三件魔法物品；织法场景想象亲吻或牵手；提夫林庆功宴选择盖尔并想着他入睡。

**第二幕：** 让埃尔明斯特稳定魔法球；拒绝伊索贝尔暗杀；月出之塔后长休触发盖尔投影；星空场景表达爱意；邪念杀恋人事件叫醒盖尔并通过豁免；殖民地面对主脑时告诉盖尔选择爱他的人；拒绝自爆。

**第三幕：** 泽希诺答案为红苹果或烤洋葱、深水城阳台、认为自己死掉更好；让盖尔读年鉴，但从不支持王冠神化；觐见密斯特拉时建议和解和归还王冠；湖上谈话说爱的是凡人盖尔；拒绝米佐拉、哈尔辛、双卓尔和其他性关系；终局拒绝盖尔自爆；摧毁耐色脑；归还王冠；接受求婚。

## 十三、绝对不能选择的选项

以下任何一项都可能让本路线偏离或直接失败：

1. 在盖尔传送点幻想砍下他的手。
2. 未处理林地冲突就进入山隘或第二幕。
3. 让阿尔菲拉成为邪念营地受害者。
4. 用远程或法术杀死明萨拉，或在击昏她后尚未杀完首领就长休。
5. 让伊索贝尔被马库斯带走。
6. 在月出之塔厨房选择努力回忆钢爪。
7. 错过盖尔第二幕投影与星空场景。
8. 在邪念杀恋人事件中不叫醒盖尔，或关键豁免失败后继续游戏。
9. 进入影界前没有救囚犯、完成暗影诅咒前置和盖尔恋爱。
10. 让影心杀死暗夜之歌。
11. 让盖尔在第二幕或终局引爆魔法球。
12. 在第三幕任何关键节点鼓励盖尔控制王冠或成为神。
13. 与米佐拉、哈勒普、双卓尔或其他同伴发生性关系。
14. 在奥林单挑中被击倒后让队友继续取胜。
15. 击败奥林后接受巴尔神选身份。
16. 在拒绝巴尔前提前用医疗术触发邪念记忆。
17. 让君主吞噬俄耳甫斯。
18. 让邪念、盖尔或卡菈克转化为夺心魔。
19. 最终控制耐色脑而不是摧毁它。

按照这条路线进行，整场游戏的情感主轴会非常完整：邪念并不是因为“原本善良”才战胜巴尔，而是在知道自己曾经是整个灾难的始作俑者之后，仍然选择成为另一个人；盖尔也不是因为失去力量才留在人间，而是在真正有机会成为神时，主动承认被一个凡人所爱已经足够。最终两人都拒绝了那个由神明、血统和力量替他们预先写好的结局。
