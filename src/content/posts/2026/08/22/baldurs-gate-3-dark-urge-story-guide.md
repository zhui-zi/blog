## 一、这套路线最终怎么玩

这套档的核心角色设定推荐为：**邪念 + 白色龙裔 + 复仇之誓圣武士 + 抗拒巴尔。** 感情线则按照：**第一章喜欢上盖尔 → 第二章与盖尔正式确立恋爱 → 拒绝杀伊索贝尔 → 邪念被迫试图杀死盖尔但成功抵抗 → 第三章遇到哈尔辛感情线 → 在盖尔和哈尔辛之间作最终选择。** 之所以这么安排，是因为盖尔不能与哈尔辛共享伴侣。哈尔辛第三章会允许你先去征求现任伴侣意见，但盖尔、威尔和莱埃泽尔都会拒绝；选择哈尔辛就必须结束盖尔恋情。

因此建议在哈尔辛第三章表白时留一个永久存档：**存档 A 最终选择盖尔，存档 B 与盖尔分手并最终选择哈尔辛。** 这是原版游戏里同时体验两人最合理、也最完整的方式。

## 二、角色创建

| 项目 | 选择 |
|---|---|
| 起源 | 邪念 |
| 种族 | 白色龙裔 |
| 背景 | 闹鬼之人，邪念固定 |
| 职业 | 复仇之誓圣武士 |
| 路线 | 抗拒邪念 |
| 定位 | 主角对话、前排、单体爆发 |
| 关键属性 | 力量16、体质14、魅力16左右 |

盖尔是法师，哈尔辛是德鲁伊，因此主角玩圣武士正好补齐队伍中的前排和魅力角色。剧情上圣武士也非常适合邪念：你不是一个本性纯洁的英雄，而是一个醒来以后不知道自己是谁，只能依靠自己立下的誓言重新定义人生的人。失忆前的邪念曾是巴尔最完美的杀戮造物；失忆后的你却给自己建立了一套“不允许自己成为怪物”的规则。如果中途因为主动屈服于邪念而破誓，也不用读档。甚至可以把它当成人物故事的一部分：**立誓 → 失控 → 破誓 → 继续抵抗 → 得知自己真实身份 → 拒绝巴尔 → 重新定义自己的誓言。**

## 三、第一章：开启盖尔恋爱

邪念第一次遇到盖尔，就是整档最危险的剧情陷阱之一。盖尔从传送法阵里伸出手时，邪念会产生一个特殊念头：**幻想砍掉那只手。**不要选。

这不是普通的幻想描述。选了以后邪念真的会把盖尔的手砍掉，盖尔永久死亡，整个恋爱路线直接结束。正确处理就是压下冲动，把盖尔拉出来。这实际上非常适合作为这档人物故事的第一幕：邪念第一次看见一个陌生人时，本能想把他的手砍下来，但最终选择把这只手握住、把他救出来。而这个人后来会成为他最重要的人之一。

盖尔整体非常喜欢：**帮助弱者、避免无意义杀戮、通过谈判解决问题、保护孩子、尊重知识与魔法。** 所以这条抗拒邪念路线天然和盖尔非常合拍。在翠绿林地里尽量救下阿拉贝拉、保护提夫林孩子、化解泽夫洛和阿拉丁的冲突，并帮助需要帮助的人，不要为了娱乐随意杀人。你不需要把邪念演成圣母，威胁敌人、说黑色幽默、出现嗜血念头都可以。

关键区别是：**“我脑子里想杀人”可以出现，但“因为有趣所以杀掉无辜 NPC”尽量不要做。** 这样既保留邪念人格，又非常符合盖尔对你的理解——他看到的是一个有危险冲动，却不断选择克制的人。

第一章盖尔会逐渐告诉你，他需要吸收魔法物品稳定耐色瑞尔魔法球。正常给他。不用心疼，那几个阶段需要的魔法物品数量有限，而且第一章有大量价值很低的魔法装备。不要长期拒绝，更不要羞辱他。这不仅涉及好感，也关系盖尔个人故事。

盖尔好感达到要求以后，会触发他教你感受魔网的营地事件。这是盖尔真正的第一阶段恋爱开关。一定参与。你们通过魔网建立连接以后，会出现让你想象某种情景并把情感传给他的选项。这里选择明显具有爱情或亲密意味的想象。

不要选：单纯朋友；敌意；结束魔网连接。完成以后，你和盖尔进入“暧昧”阶段。盖尔的恋爱在第一章主要停留于这种精神层面的接近，真正确定关系发生在第二章。

## 四、第一章：保住哈尔辛、阿尔菲拉与其他队友

这一档当然必须：**救哈尔辛。**不要屠林地。正常调查卡哈、处理地精营地，救出哈尔辛。

为了保留最多剧情：**明萨拉不要杀，使用非致命攻击击晕。**这样第二章仍然可以在月出之塔招募她。第一章哈尔辛还不是正式恋爱对象。他的主要精力全部放在幽影诅咒，因此即使你与他有一些暧昧对话，也不会影响盖尔恋爱。哈尔辛真正可以成为伴侣要到第三章。

追求最大内容量的话，建议救阿尔菲拉。邪念必定会在第一章营地杀死一名吟游诗人，如果阿尔菲拉正常来到营地，死的就是她。如果在事件发生前使用非致命攻击提前把她击晕，则会由另一名龙裔吟游诗人 Quil 顶替。

这样阿尔菲拉可以继续活到第二、第三章。如果你更在乎第一次邪念体验的戏剧冲击，也可以不救她。但这是一份“最大内容量攻略”，所以推荐：**击晕阿尔菲拉，让 Quil 成为受害者。**

事后与盖尔和其他队友谈这件事时，角色扮演方向建议是：**承认自己出了问题，而不是为杀戮感到骄傲。**

这档不要做纯恶路线。尽量保住：盖尔、影心、莱埃泽尔、阿斯代伦、威尔、卡菈克、哈尔辛、明萨拉。幽暗地域和养育间也不是二选一。

建议：**先完整探索幽暗地域，再前往玫晨修道院和吉斯洋基养育间。**这样莱埃泽尔和影心的大量剧情都不会漏。

## 五、第二章：与盖尔正式确立恋爱

进入幽影诅咒之地前后，会遇到伊尔明斯特。一定正常与他交谈。他会稳定盖尔胸口的耐色瑞尔魔法球，并转达密斯特拉的命令：**盖尔应该牺牲自己，用魔法球摧毁至上真神。**

不要鼓励盖尔立刻去死。这会成为盖尔第二章人物线的核心。盖尔原本认为自己犯了巨大错误，觉得如果密斯特拉要求自己以死赎罪，那么自己的生命也许真的只剩下这种价值。

你的邪念却恰好可以成为那个告诉他**“人的过去不等于人的全部价值”**的人，而这句话对于邪念本人其实同样成立。这组恋爱没有阿斯代伦 × 邪念那么直接，但主题非常漂亮：两个人都被过去压得喘不过气。

盖尔认为：**“我犯下了不可挽回的错误，所以也许我应该死。”** 邪念则逐渐意识到：**“我曾经犯下的根本不是一个错误，而是一生的屠杀。”**

盖尔需要学习的是：**犯错以后仍然值得活着。** 邪念需要学习的是：**过去不能替现在作决定。** 于是两个人都在对方身上看到同一个问题：**如果我相信你不应该因为过去而死，那么我是不是也必须允许自己继续活下去？** 这就是这条恋爱线最有意思的地方。

进入第二章并推进到月出之塔附近后，在盖尔好感足够的情况下会出现他的正式恋爱事件。他会通过魔法投影邀请你单独见面，一定接受邀请。盖尔会谈到密斯特拉、耐色瑞尔魔法球、死亡以及他对你的感情。

这里明确回应他的爱意，并选择和他一起度过这一晚。完成以后，盖尔会从“暧昧”正式进入**伴侣状态**，从这时开始把你视为自己的恋人。这一点非常重要，因为接下来邪念最关键的一夜才能稳定指向**盖尔**。

## 六、第二章：拒绝伊索贝尔任务并救下盖尔

管家会要求邪念**杀死伊索贝尔**，一定拒绝。伊索贝尔一旦死亡，不只是一个 NPC 没了，而是会影响整个终焉光芒旅店以及大量人物。更重要的是，拒绝杀伊索贝尔以后，才能触发抗拒邪念最重要的情感剧情。

管家会重新出现，并告诉你：既然不愿杀伊索贝尔，那你就杀掉**自己最珍视的人**。如果已经正式恋爱盖尔，目标通常就会是盖尔。恋爱对象优先成为这场事件的受害目标；盖尔在伊尔明斯特稳定魔法球后也具备成为目标的条件。

这是整档最重要的剧情存档点之一。管家离开以后，你会站在熟睡的盖尔旁边。千万不要继续睡、主动杀他或屈服于邪念。

选择**叫醒盖尔**，告诉他发生了什么，然后通过关键的 **DC14 感知豁免**。成功以后，盖尔会帮助控制你，陪着你熬过这一夜。后续还有额外的感知豁免，可以表现出理解或感谢。

进入这个长休以前，建议保留 4 点灵感，卸掉会让感知豁免处于劣势的装备，并尽量增加感知豁免。这里失败的代价非常严重。如果邪念真的杀掉恋人，第二天还可能需要进行 DC30 欺瞒，否则整个营地都会与你敌对。

这场戏放在盖尔身上会形成一个非常漂亮的反转。此前一直是：**盖尔觉得自己可能会爆炸，害怕自己会毁掉所有人。**而这一夜变成：**邪念才是那个可能失控杀死爱人的人。**

你们两个人身体里都存在某种自己无法完全掌控的毁灭力量：盖尔胸口是耐色瑞尔魔法球；邪念身体里是巴尔的杀戮冲动。两个人都必须相信另一方一句话：**“你现在还没有变成那个最坏的结果。”**

## 七、第二章：完成哈尔辛与贾希拉路线

虽然这时候你的恋人是盖尔，但哈尔辛线必须同时推进。第二章一定彻底解除幽影诅咒，核心步骤如下：

1. 找到昏迷的 **Art Cullagh**，前往治疗中心处理 **Malus Thorm**。
2. 取得鲁特琴并唤醒 Art，告诉哈尔辛关于 Thaniel。
3. 保护哈尔辛开启传送门，救回 Thaniel。
4. 寻找 Oliver，让 Oliver 与 Thaniel 重新融合。
5. 击败凯瑟里克，离开第二章时确认土地开始恢复。

尤其是让 Oliver 重新与 Thaniel 融合，对哈尔辛好感提升非常大；相关选择本身也非常符合他重视生命与自然恢复的价值观。如果没有彻底解除幽影诅咒就进入第三章，哈尔辛会留下处理诅咒，恋爱线也就没了。

建议让**影心拒绝杀死暗夜之歌**，这样能保住更多人物和第三章内容。月出之塔大战必须确保**贾希拉活下来**，凯瑟里克死亡以后再正式邀请她加入。因为第三章邪念真正进入巴尔剧情时，贾希拉和明斯克是最重要的两个队友。

## 八、第三章：盖尔与哈尔辛的感情分叉

进入第三章以后，同时有三条重要剧情：**邪念寻找自己的过去；盖尔面对卡尔萨斯王冠与密斯特拉；哈尔辛终于允许自己考虑爱情。** 不要急着一路冲奥林。先完成利文顿的大量内容，并开始推进盖尔、哈尔辛和贾希拉的剧情。

哈尔辛喜欢保护生命、帮助儿童和动物、怜悯弱者、保护自然，并避免不必要的残酷。因此这条“抗拒邪念”路线非常容易获得他的高好感。对哈尔辛来说，你不是因为天生善良才做这些事情。

恰恰相反，你的身体不断要求**杀**，但你仍然一次又一次选择**救**。这其实比普通英雄更加符合他的自然观：重要的不是生命有没有黑暗本能，而是最终选择让什么东西生长。

完整解除幽影诅咒并拥有足够好感以后，在利文顿或下城区长休，哈尔辛可以向你表达感情。他知道你已经和盖尔在一起，所以不会要求你偷偷背叛盖尔，而是让你**去问盖尔**。这里是整个恋爱路线最大的分叉，马上建立一个名为“恋爱分支——盖尔/哈尔辛”的永久手动存档，以后不要覆盖。

## 九、分支 A：最终选择盖尔

去找盖尔讨论哈尔辛。盖尔会明确表示：**不接受。**这不是好感不够，也不是对话选错。

盖尔本身就是严格的一对一关系角色。因此如果最终选择盖尔，就**拒绝哈尔辛**，然后继续盖尔第三章完整恋爱线。

这一条路线可以看到第一章魔网暧昧、第二章完整恋爱夜、邪念差点杀死盖尔的专属事件、第三章盖尔完整感情结局，以及最终的盖尔伴侣结局。但相应地会失去哈尔辛正式恋爱场景和伴侣结局。

盖尔看到《卡尔萨斯编年史》以及卡尔萨斯王冠以后，会重新产生巨大野心。他开始认为：如果掌握王冠，也许自己可以超越凡人的限制。这时候非常关键。如果你想要最符合这条“抗拒邪念”路线的盖尔结局，不建议不断鼓励他的神格野心。

因为邪念整个故事恰好是在**拒绝成为巴尔想让你成为的东西**。如果最后却告诉盖尔**“你必须成为神才足够伟大”**，主题会有点冲突。更适合的方向是告诉盖尔，他本身已经足够。

在第三章星界小船恋爱场景里，可以劝他放弃通过王冠证明自己的执念。盖尔能够承认：他可以没有神格，但无法想象没有你。

建议让盖尔正常前往风暴海岸礼拜堂与密斯特拉见面。但你不需要把这理解成：**“让盖尔重新回去当密斯特拉的宠物。”**这条人物线真正需要解决的是：盖尔是否还需要永远依靠密斯特拉的认可判断自己的价值。

最适合抗拒邪念主题的答案是：**不需要。**就像邪念最后拒绝巴尔一样。父神、女神、创造者、前任导师都不能替一个人定义全部人生。

## 十、分支 B：最终选择哈尔辛

重新读取第三章哈尔辛表白时的永久存档。这次去问盖尔以后，当盖尔要求二选一：**选择哈尔辛。**这会结束与盖尔的恋爱关系，之后盖尔进入前伴侣状态，但不会因此离队。

随后回去告诉哈尔辛。下一次长休即可进入哈尔辛的正式恋爱场景。完成以后，你与哈尔辛正式成为伴侣。他会明确告诉你，他对爱情的理解比较开放和流动，但因为盖尔不接受这种模式，你此时实际上已经只与哈尔辛保持正式关系。

如果你最后选择哈尔辛，这段故事并不一定要理解成：**“喜新厌旧，把盖尔甩了。”**更适合作为角色故事理解的是：盖尔属于邪念恢复自我的那段旅程。在邪念最害怕自己的时候，是盖尔陪他度过了第二章那场最危险的夜。

盖尔证明了一件事：**即使知道你可能杀死他，也有人愿意相信你。** 哈尔辛则属于邪念获得自由后的未来，他代表自然、治愈、重新生长、新的家庭，以及不再围绕神、权力和过去生活。所以两人分别对应邪念人生的两个阶段：**盖尔代表在黑暗中学会相信自己仍值得被爱；哈尔辛代表摆脱黑暗以后学习怎样真正生活。**

## 十一、第三章尽早招募明斯克

推进贾希拉任务，前往清点所调查石王，再进入下水道找到明斯克。最终战斗时打开**非致命攻击**，把明斯克击晕。

不要杀。贾希拉存活并完成相关条件以后，可以让皇帝把明斯克纳入保护范围，从而正式招募。从此以后，巴尔相关剧情建议优先使用：**邪念 + 贾希拉 + 明斯克 + 当前恋人。**

如果最终选择盖尔：**邪念 + 盖尔 + 贾希拉 + 明斯克。**如果最终选择哈尔辛：**邪念 + 哈尔辛 + 贾希拉 + 明斯克。**

## 十二、第三章：完成邪念的巴尔主线

第一次正式见戈塔什时，邪念会获得大量普通 Tav 没有的内容。把所有和过去、奥林、至上真神、你们之间的关系及原始计划有关的对话全部问完。

你会发现，原本至上真神计划的核心搭档根本不是**戈塔什 + 奥林**，而是**戈塔什 + 邪念**。你和戈塔什才是最初策划卡尔萨斯王冠、控制主脑和至上真神阴谋的人。奥林只是后来偷袭你并取代了你。这一幕是邪念身份剧情最大的反转之一。

进入谋杀裁判所去见沙洛佛克时，推荐使用**邪念 + 贾希拉 + 明斯克 + 恋人**。不要一见沙洛佛克就开战，让所有对话说完。

贾希拉和明斯克是一百多年前真正与沙洛佛克打过交道的人，所以这里存在大量非常有意义的前代《博德之门》呼应。最终建议**拒绝成为巴尔的不洁刺客**，然后**杀死沙洛佛克**。上一代最著名的堕落巴尔之裔与这一代巴尔最完美的孩子面对面，而邪念选择：**我不会成为你。**

进入巴尔神殿以后，邪念与奥林会进入独特的**一对一决斗**。这是复仇圣武士发挥优势的时候，提前准备好高等级至圣斩、加速类效果、提高命中的手段和高 AC，并把爆发资源全部留给奥林。最好让邪念自己获胜，不要故意输掉再让队友收尾。

这不仅是战斗，也是人物剧情：奥林当初靠偷袭毁掉邪念的大脑、夺走他的身份。现在巴尔把两个人重新放到一起，没有偷袭，没有阴谋，只有**谁才是巴尔真正的孩子**。然后你击败她。

这是整档真正的高潮。巴尔终于重新承认你。你得到过去的邪念梦寐以求的一切：父亲的认可、选民身份、巴尔的力量，以及继续进行杀戮的资格。选择**拒绝巴尔**。

巴尔会抽走属于他的血，杀死邪念。随后守墓人介入，把你重新带回世间。这个复活后的邪念第一次真正意义上：**不再属于巴尔。**

## 十三、两种恋爱结局的意义

### 如果最终选择盖尔

这是两个曾经被神定义人生的人最终选择凡人生活。邪念拒绝：**“你是巴尔之子，所以你必须杀戮。”** 盖尔拒绝：**“你曾经失败，所以必须成为神才能证明价值。”** 两个人最终接受：**作为凡人也已经足够。** 这是更加浪漫、精神性也更强的一条结局。

### 如果最终选择哈尔辛

这是**死亡 → 新生**的结构。邪念曾经存在的意义是制造尸体。

最终却与一个把一生投入恢复生命的人走到一起。哈尔辛在结局以后会返回解除诅咒后的土地，帮助自然恢复并照顾大量因为战争而失去家庭的孩子。只与哈尔辛保持伴侣关系时，你可以选择跟他一起去。

于是整个邪念人生形成一个非常漂亮的闭环：**过去制造孤儿，现在照顾孤儿；过去散播死亡，现在帮助土地重新生长。** 这可能是邪念所有善线结局里最有“重获新生”意味的一种。

## 十四、最终战

无论最终选择盖尔还是哈尔辛：**不要让盖尔自爆。**第一次邪念抗拒档没有必要靠牺牲盖尔解决最终Boss。正常进入耐色脑最终战。

最后选择**摧毁耐色脑**，不要控制，因为这一整档讲的都是**拒绝让别人控制自己**。如果最后邪念自己坐上耐色脑王座控制所有人，前面的主题就会彻底反转。当然这非常适合下一次“拥抱邪念”恶人档。

## 十五、两条最终路线速查

### A线：最终伴侣盖尔

- 第一章：**救盖尔 → 魔网教学选择浪漫 → 救林地 → 救哈尔辛。**
- 第二章：**伊尔明斯特稳定盖尔 → 盖尔正式恋爱 → 不杀伊索贝尔 → 抵抗杀死盖尔 → 完成哈尔辛解除幽影诅咒 → 招募贾希拉。**
- 第三章：**招募明斯克 → 哈尔辛表白 → 问盖尔 → 盖尔拒绝开放关系 → 选择盖尔 → 完成盖尔密斯特拉/卡尔萨斯路线 → 劝盖尔不需要神格证明自己 → 沙洛佛克 → 奥林 → 拒绝巴尔 → 摧毁耐色脑。** 最终主题是**两个被神与过去束缚的人，最终选择作为自己活下去**。

### B线：最终伴侣哈尔辛

第一、二章完全相同。第三章：**哈尔辛表白 → 留永久存档 → 找盖尔谈话 → 选择结束盖尔恋爱 → 回到哈尔辛身边 → 完成哈尔辛正式恋爱 → 招募明斯克 → 沙洛佛克 → 奥林 → 拒绝巴尔 → 摧毁耐色脑 → 跟哈尔辛返回解除诅咒后的土地。** 最终主题是**一个为死亡而生的人，最终选择照顾生命**。

## 十七、我最推荐哪个最终伴侣

如果你更喜欢**人物之间的精神呼应和爱情故事完整度**，就选盖尔。邪念和盖尔的故事可以理解成：**“我知道你最糟糕的过去，也知道你最危险的部分，但我不认为你因此就应该去死。”** 而这句话两个人都可以对彼此说。

如果你更喜欢**邪念整个人生的救赎与结局象征**，就选哈尔辛。因为邪念最后跟随哈尔辛离开权力中心，去重建一块曾经死亡的土地，是一种非常彻底的：**“我不再需要证明自己是谁，我只想开始生活。”**

如果是我替这档做剧情排序，我会优先推荐**第一周目分支读取两个结局都看**。先通一次盖尔结局，然后读取【哈尔辛表白】永久档，转哈尔辛再看一次后半程。这样盖尔和哈尔辛两条感情线都不是简单“刷场景”，而会形成两个完全不同、但都非常适合抗拒邪念的结局。
